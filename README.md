# Modo W

Checklist diario personal para hábitos, suplementos y entrenamiento.

## Funciones

- Checklist editable.
- Una tarea completada queda bloqueada hasta el próximo día.
- El día operativo cambia a las 00:01.
- Historial semanal, mensual y anual.
- Estadísticas de cumplimiento, días perfectos y racha.
- Datos guardados localmente en SQLite.
- Funciona offline.

## APK

GitHub Actions compila automáticamente una APK de prueba en cada cambio sobre `main`.

La APK aparece dentro de la ejecución `Build Modo W APK`, en la sección **Artifacts**, con el nombre `ModoW-APK`.
